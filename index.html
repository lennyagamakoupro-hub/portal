Installer

Sur ton ordinateur.

Pyli n'est pas encore signé par Apple ni par Microsoft. Ton ordinateur va donc demander une confirmation une fois : voici exactement où cliquer.

  1. Télécharge Pyli pour Mac

    Safari ouvre le fichier tout seul et crée un dossier « Pyli » dans Téléchargements. Avec un autre navigateur, double-clique sur Pyli.zip.

    Télécharger pour Mac

  2. Ouvre « Installer Pyli »

    Dans le dossier Pyli, double-clique sur « Installer Pyli ».

  3. Confirme que tu veux l'ouvrir

    La première fois, macOS refuse de l'ouvrir et parle d'un développeur non identifié, ou d'un logiciel qu'Apple ne peut pas vérifier. Ferme ce message, puis :

    Réglages Système›Confidentialité et sécurité›Ouvrir quand même
    Le bouton est tout en bas

    Descends dans « Confidentialité et sécurité » jusqu'à la ligne qui cite « Installer Pyli », clique « Ouvrir quand même », puis confirme avec ton mot de passe. Sur un Mac plus ancien (macOS 14 ou avant), un clic droit sur « Installer Pyli » puis « Ouvrir » suffit.

  4. Laisse faire

    Une fenêtre de Terminal s'ouvre et installe Pyli en quelques secondes. Si le Mac demande l'accès au réseau local ou au dossier Téléchargements, réponds « Autoriser » : c'est ce qui permet à ton téléphone de lui parler.

  5. Le code s'affiche

    Une page s'ouvre avec ton code de connexion. Garde-la ouverte et passe à « Relier ». Pour la retrouver plus tard : « Pyli — mon code » sur ton Bureau.

  1. Télécharge Pyli pour Windows

    Le fichier Pyli-Windows.zip arrive dans Téléchargements.

    Télécharger pour Windows

  2. Extrais le dossier

    Ne lance rien depuis le zip : l'installation refuse de démarrer de là.

    Clic droit sur Pyli-Windows.zip›Extraire tout…›Extraire

  3. Ouvre « Installer Pyli »

    Dans le dossier Pyli extrait, double-clique sur « Installer Pyli ».

  4. Si Windows affiche « Windows a protégé votre ordinateur »

    C'est le filtre de Windows pour les logiciels qu'il ne connaît pas encore.

    Informations complémentaires›Exécuter quand même

  5. Autorise le réseau privé

    Si le pare-feu Windows demande l'accès pour Pyli, laisse « Réseaux privés » coché et clique « Autoriser ». Sans ça, ton téléphone ne trouve pas l'ordinateur.

  6. Le code s'affiche

    Une page s'ouvre avec ton code de connexion. Pour la retrouver plus tard : « Pyli - mon code » sur ton Bureau.

  1. Télécharge Pyli pour Linux

    Pour les PC classiques (processeur x86_64). Décompresse Pyli-Linux.zip : un dossier « Pyli » apparaît.

    Télécharger pour Linux

  2. Lance l'installation

    Ouvre un terminal dans le dossier Pyli, puis :

    bash installer-pyli.sh

  3. Ouvre le pare-feu si besoin

    Si ton téléphone ne trouve pas l'ordinateur, autorise Pyli sur le réseau local.

    Ubuntu :

    sudo ufw allow 8150/tcp && sudo ufw allow 8151/udp

    Fedora :

    sudo firewall-cmd --permanent --add-port=8150/tcp --add-port=8151/udp && sudo firewall-cmd --reload

  4. Le code s'affiche

    Ton navigateur ouvre la page avec ton code de connexion. Pyli démarre ensuite à chaque connexion à ta session.

Relier ton téléphone

Un scan, et c'est pour de bon.

  1. Le même Wi-Fi

    Ton téléphone et ton ordinateur sur le même réseau. Le partage de connexion de ton téléphone marche aussi.

  2. Le code sur l'ordinateur

    La page qui s'est ouverte après l'installation, ou « Pyli — mon code » sur le Bureau.

  3. Scanne avec l'appareil photo

    Touche le lien qui apparaît : Pyli s'ouvre dans le navigateur.

  4. Laisse-toi guider

    Lance la carte d'essai : le portail s'ouvre sur ton ordinateur. Tu sais envoyer.

  5. Garde-la sur l'écran d'accueil

    Sur iPhone : Partager, puis « Sur l'écran d'accueil ». Sur Android : menu, puis « Ajouter à l'écran d'accueil ».

Les gestes

Trois gestes, rien d'autre.

ton ordi

Vers la gauche

La carte part sur ton ordinateur et sort d'un portail sur l'écran.

un collègue

Vers le haut

Choisis un collègue du même Wi-Fi : son ordinateur ou son téléphone. Il accepte, ou il refuse.

Recevoir

Ce qu'on t'envoie sort d'un portail sur ton téléphone. Une photo, une vidéo, un document, un lien.

Pour garder ce que tu reçois : Photos sur une image (reste appuyé dessus, puis « Ajouter à Photos »), Fichiers sur une vidéo ou un document (rangés dans Fichiers, Téléchargements).

Questions

Si quelque chose bloque.

Mon téléphone ne trouve pas mon ordinateur

Vérifie qu'ils sont sur le même Wi-Fi. Un Wi-Fi « invité » isole souvent les appareils entre eux : prends le réseau principal, ou le partage de connexion de ton téléphone.

Sur Windows et Linux, le pare-feu doit laisser passer Pyli sur le réseau privé (voir l'installation). Si l'appli dit « Code manquant », rescanne le code affiché sur l'ordinateur.

Que se passe-t-il si mon ordinateur est éteint ?

Pyli vit sur ton ordinateur : éteint ou en veille, ton téléphone ne peut rien lui envoyer. L'appli te le dit clairement.

Une carte lancée à ce moment-là n'est pas perdue : elle reste sur ton téléphone avec la mention « En attente », et part toute seule dès que l'ordinateur répond, même si tu as fermé l'appli entre-temps.

Comment relier un nouveau téléphone ?

Ouvre « Pyli — mon code » sur le Bureau de ton ordinateur et scanne-le avec le nouveau téléphone. Sur Linux, ou si le raccourci a disparu, ouvre http://127.0.0.1:8150/bienvenue dans le navigateur de l'ordinateur.

Comment fonctionnent les mises à jour ?

Toutes seules. Pyli vérifie s'il existe une nouvelle version quelques minutes après le démarrage, puis toutes les six heures. Chaque version est signée : une version qui ne porte pas la bonne signature est refusée.

Tu n'as rien à refaire, ni à rescanner le code.

Comment désinstaller Pyli ?

Dans le dossier Pyli que tu as téléchargé : « Desinstaller Pyli » sur Mac et Windows, bash desinstaller-pyli.sh sur Linux. Les fichiers déjà reçus restent dans Téléchargements, dossier Portal.

Mes fichiers passent-ils par Internet ?

Non. Ils vont directement de ton téléphone à ton ordinateur par ton réseau, sans serveur, sans compte et sans stockage en ligne. Entre deux collègues, ils sont en plus chiffrés de bout en bout.

Pyli ne se connecte à Internet que pour vérifier et télécharger ses mises à jour, depuis GitHub.
