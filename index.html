    Confidentialité

    Vos fichiers restent chez vous.

    Ce que Pyli fait de vos fichiers, et ce qu'il ne fait pas. Chaque point ci-dessous correspond au fonctionnement réel du programme.

    Directement sur votre réseau

    Vos fichiers vont du téléphone à l'ordinateur par votre Wi-Fi, sans passer par un serveur. Pyli refuse toute connexion qui ne vient pas de votre réseau local.

    Aucun cloud, aucun compte

    Rien n'est stocké en ligne. Ce que vous envoyez arrive dans le dossier Téléchargements de votre ordinateur, dans « Portal », et nulle part ailleurs.

    Une connexion privée

    Chaque ordinateur a son propre code d'accès, transmis par le QR code. Sans ce code, l'ordinateur refuse les envois. Si vous pensez qu'il a circulé, désinstallez puis réinstallez Pyli : un nouveau code est créé, et l'ancien ne marche plus.

    Chiffré entre collègues

    Entre deux ordinateurs Pyli, les fichiers sont chiffrés de bout en bout. Entre votre téléphone et votre ordinateur, ils ne sont pas chiffrés : ils restent sur votre réseau et sont protégés par votre code d'accès. Évitez donc les Wi-Fi publics.

    Internet, seulement pour les mises à jour

    Pyli se connecte à Internet pour une seule chose : vérifier et télécharger ses mises à jour sur GitHub. Chaque mise à jour est signée par son auteur et chaque fichier a une empreinte SHA-256. Une version mal signée ou un fichier modifié sont refusés, et votre version actuelle reste en place. Vos fichiers, eux, ne sortent jamais sur Internet. Sur le réseau local, Pyli signale aussi sa présence pour que vos collègues puissent vous trouver.

    Questions

    Si quelque chose bloque.

    Mon téléphone ne trouve pas mon ordinateur

    Vérifiez qu'ils sont sur le même Wi-Fi. Un Wi-Fi « invité » isole souvent les appareils : prenez le réseau principal, ou le partage de connexion de votre téléphone.

    Sur Windows et Linux, le pare-feu doit laisser passer Pyli sur le réseau privé (voir l'installation). Si l'appli indique « Code manquant », rescannez le code affiché sur l'ordinateur.

    Que se passe-t-il si mon ordinateur est éteint ?

    Pyli fonctionne sur votre ordinateur : éteint ou en veille, il ne peut rien recevoir. L'appli du téléphone vous l'indique clairement.

    Une carte lancée à ce moment-là n'est pas perdue. Elle reste sur le téléphone avec la mention « En attente du Mac », et part toute seule dès que l'ordinateur répond, même si vous avez fermé l'appli entre-temps.

    Comment relier un nouveau téléphone ?

    Ouvrez « Pyli — mon code » sur le Bureau de votre ordinateur et scannez-le avec le nouveau téléphone. Sur Linux, ou si le raccourci a disparu, ouvrez http://127.0.0.1:8150/bienvenue dans un navigateur de l'ordinateur.

    Quels systèmes et processeurs sont compatibles ?

    Mac : macOS 11 ou plus récent, processeur Apple (M1 et suivants) ou Intel, avec le même fichier. Windows : 64 bits, processeur Intel ou AMD. Linux : processeur Intel ou AMD (x86_64), avec un bureau graphique pour les animations.

    Pas de version pour les processeurs ARM sous Windows ou Linux pour l'instant. Côté téléphone : iPhone et Android, avec un navigateur à jour.

    L'installation échoue : que faire ?

    Lisez le message affiché à la fin de l'installation. « Le port 8150 est pris » signifie qu'un autre programme utilise la place de Pyli : redémarrez l'ordinateur puis relancez l'installation. Sur Windows, vérifiez que vous avez bien extrait le zip avant de lancer « Installer Pyli ».

    Sinon, le journal de Pyli explique ce qui s'est passé (voir « Assistance » plus bas).

    Comment fonctionnent les mises à jour ?

    Toutes seules. Pyli vérifie s'il existe une nouvelle version un peu après le démarrage de l'ordinateur, puis toutes les six heures. Il vérifie la signature de la version et l'empreinte de chaque fichier avant de remplacer quoi que ce soit. Si la nouvelle version ne démarre pas, il revient à la précédente.

    Vous n'avez rien à refaire, ni à rescanner le code.

    Comment vérifier la version installée ?

    Ouvrez « Pyli — mon code » sur votre ordinateur, ou http://127.0.0.1:8150/bienvenue : la date de la version installée s'affiche en bas de la page. Comparez-la avec la version du 16 novembre 2026 proposée ici.

    Comment récupérer une version précédente ?

    Toutes les versions restent disponibles sur la page Versions précédentes. Sachez qu'une ancienne version se met à jour d'elle-même vers la plus récente quelques minutes après son installation.

    Si une mise à jour pose problème, Pyli revient de lui-même à la version d'avant lorsque la nouvelle ne démarre pas.

    Comment désinstaller Pyli ?

    Dans le dossier Pyli téléchargé : « Desinstaller Pyli » sur Mac et Windows, bash desinstaller-pyli.sh sur Linux. Les fichiers déjà reçus restent dans Téléchargements, dossier « Portal ».

    Mes fichiers passent-ils par Internet ?

    Non. Ils vont directement de votre téléphone à votre ordinateur par votre réseau, sans serveur, sans compte et sans stockage en ligne. Entre deux collègues, ils sont en plus chiffrés de bout en bout.

    Pyli ne se connecte à Internet que pour vérifier et télécharger ses mises à jour, sur GitHub.

    Comment signaler un problème ?

    Décrivez ce que vous faisiez et joignez le journal de Pyli (voir « Assistance »). Vous pouvez l'envoyer à la personne qui vous a recommandé Pyli, ou ouvrir un signalement public sur GitHub.

    Ne publiez jamais votre QR code ni le lien qu'il contient : ils donnent accès à votre ordinateur.

    Assistance

    Le journal dit tout.

    Pyli note ce qu'il fait dans un fichier texte. C'est la première chose à regarder, et à transmettre si vous demandez de l'aide.

    Sur Mac

    Dans le Finder : Aller › Aller au dossier, puis :

    ~/Library/Application Support/Lancer/serveur.log

    Sur Windows

    Touche Windows + R, puis :

    %LOCALAPPDATA%\Lancer\serveur.log

    Sur Linux

    Dans votre dossier personnel :

    ~/.local/share/portal/serveur.log
